# 工具与 Hooks

| <div style="width: 14ch;">模块 (Module)</div> | 说明 |
| --- | --- |
| [config](./config.zh-CN.md) | 全局参数与接口配置模块，提供 `setRestOptions` 与 `setGlobalConfig` 覆盖默认配置 |
| [requests](./requests.zh-CN.md) | HTTP 请求模块（`apiTools`），提供 axios 实例、拦截器、`useSafeRequest` 等 |
| [hooks](./hooks.zh-CN.md) | React Hooks 集合：localStorage/sessionStorage、定时器、防抖等 |
| [type-tools](./type-tools.zh-CN.md) | 类型判断工具函数：`isNull`、`isBlank` 等 |
| [validators](./validators.zh-CN.md) | 表单验证函数集合，提供 `expansionValidator`、`remoteValidator` 等校验能力 |
