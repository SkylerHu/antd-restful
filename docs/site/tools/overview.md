# Tools & Hooks

| <div style="width: 14ch;">Module</div> | Description |
| --- | --- |
| [config](./config.md) | Global parameters and API configuration module, providing `setRestOptions` and `setGlobalConfig` to override default settings |
| [requests](./requests.md) | HTTP request module (`apiTools`), providing axios instance, interceptors, `useSafeRequest`, and more |
| [hooks](./hooks.md) | React Hooks collection: localStorage/sessionStorage, timers, debouncing, and more |
| [type-tools](./type-tools.md) | Type checking utility functions: `isNull`, `isBlank`, and more |
| [validators](./validators.md) | Form validation function collection, providing `expansionValidator`, `remoteValidator`, and other validation capabilities |
